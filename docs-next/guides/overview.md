# Product Overview

TriOrb BASE is an autonomous mobile robot (AMR) platform with omnidirectional
motion realized by three omniwheels.

This site provides:

- **Autonomous Navigation API**: ROS 2 topics / services / actions for driving the robot
- **Collaborative Navigation API**: additional APIs for multi-robot cooperative transport
- **Control ECU Library**: a Python library for sending commands to the TriOrb control ECU directly from a host PC
- **Changelog / Terms of Service / Privacy Policy**

## Before you start

For hardware setup and initial software installation, refer to the separately
distributed documents:

- TriOrb BASE Operating Manual
- Autonomous Navigation Package User Manual
- Upgrade Procedures

This site focuses on the public API surface and change history of the ROS 2 /
Python layer.
